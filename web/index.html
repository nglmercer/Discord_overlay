Discord Overlay Proxy

Transparent Streamkit overlay with custom avatars for TikTok Live Studio.

  • /overlay — proxied overlay (redirects to the Streamkit path)
  • /overlay?target=URL — override Streamkit URL
  • /overlay?debug=1 — overlay with the status message on
  • /css — preview generated CSS
  • /assets/… — local images from {{ASSETS_DIR}}
  • /health — liveness

Hot reload

Save config.toml and every open /overlay (OBS / TikTok Live Studio browser sources included) refreshes itself within a second. A config with a syntax error is ignored and the previous one stays live, so the overlay never goes blank.

Changing assets.dir is the one setting that still needs a restart.

Blank overlay?

A transparent overlay that has not connected looks the same as a broken one. Open /overlay?debug=1 and it will say whether Discord is closed, the channel is empty, or Streamkit never loaded. It is off by default so it can never appear on stream, waits 1.5s before showing anything, and hides itself for good once the overlay goes live. Set show_status = true under [overlay] to leave it on while you set things up.

Local images

Drop files in {{ASSETS_DIR}}, then reference them in config.toml:

[users.YOUR_DISCORD_ID]
idle_url = "alice-idle.png"
speaking_url = "alice-speaking.png"

They are served as {{PUBLIC_BASE_URL}}/assets/… (absolute URLs, so Streamkit’s base tag cannot break them).
